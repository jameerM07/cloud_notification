Decoupled Asynchronous Workflow

1
Client POST Request
Web browser submits form via fetch('/send-notification')
2
Persistence & Enqueue
Flask validates input, saves as PENDING in SQLite, and pushes payload into Redis list.
3
Immediate 201 Response
Client is unblocked instantly without waiting for network email delivery.
4
Asynchronous Worker Execution
worker.py pops task atomically, marks PROCESSING, simulates dispatch, and completes as SENT or FAILED.
Database: SQLite (WAL Mode Active)
Redis Host: 127.0.0.1:6379
Reliable Pattern: BRPOPLPUSH (Zero Message Loss)
